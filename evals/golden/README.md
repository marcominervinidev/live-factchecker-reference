# Synthetic excerpts

The private project measures and tests against a Golden Set of excerpts from broadcast recordings. That corpus
cannot be published. This directory holds two synthetic excerpts with the same structure and generated pseudo-words
instead (`source.md` in each); the tests of this copy reference them as `golden: <slug> mm:ss-mm:ss`
(`tests/fixtures/README.md`). The measurement harness of the private project is not part of this copy.
